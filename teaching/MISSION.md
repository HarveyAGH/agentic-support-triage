# Teaching Mission

## Mission

Become hireable as an AI engineer as fast as possible by building explainable, resume-worthy projects that prove practical skill with agent orchestration, evaluation, retrieval, MCP, APIs, and deployment.

## Why This Matters

The learner is 23, has no degree, and needs portfolio proof strong enough to compete for AI Engineer, LLM Engineer, GenAI Engineer, and Backend AI Engineer roles. Teaching should stay tied to job-market proof, not abstract theory.

## Current Focus

- LangGraph and LangChain agent orchestration
- Supervisor-as-tools delegation
- Deterministic and LLM-as-judge evaluations
- RAG and retrieval fundamentals
- MCP tools and service integration
- FastAPI, async Python, and Docker for deployable systems

## Teaching Constraints

- Prefer practical examples from the learner's existing repos.
- Keep each lesson small enough to finish quickly.
- Require the learner to explain the concept in plain English before calling it resume-ready.
- Use official or high-trust resources when introducing new technology.
- Separate "resume skill" from "full project" honestly.

## Success Criteria

The learner can:

1. Explain each project architecture without reading code.
2. Show working terminal output or traces for every resume claim.
3. Debug common failures in agents, evals, retrieval, MCP tools, and APIs.
4. Convert finished work into accurate resume bullets.
5. Apply for AI engineering roles with a coherent project story.
