Lesson 0002: FastAPI Is The Doorway To Your Agent

Mission link: this turns your agent from a terminal demo into a backend AI service that another app can call.

The Concept

Your current agent is callable only by running Python directly. FastAPI gives it an HTTP doorway.

current:
uv run python agent/agent.py
you type into terminal

target:
POST http://localhost:8000/triage
another app sends JSON

The Three Layers

Do not mix these up:

Uvicorn = the running server process
FastAPI = the web app/router
Your agent = the business logic called by the endpoint

The First Endpoint

The first endpoint should be tiny. Its only job is to prove another program can call your agent.

POST /triage
request:
{
  "message": "i was charged twice",
  "thread_id": "demo-1"
}

response:
{
  "answer": "...",
  "routes_called": ["route_to_billing"],
  "needs_escalation": false
}

Why Pydantic Models Matter

FastAPI uses Pydantic models to define the request and response contract. This is not decoration. It is how you make the API predictable.

class TriageRequest(BaseModel):
    message: str
    thread_id: str = "api-demo"

class TriageResponse(BaseModel):
    answer: str
    routes_called: list[str]
    needs_escalation: bool

Build Order

  1. Add FastAPI and Uvicorn dependencies.
  2. Create api/main.py.
  3. Add GET /health to prove the server runs.
  4. Add request and response models.
  5. Add POST /triage.
  6. Call the existing LangGraph app from the endpoint.
  7. Extract the final answer, route tool names, and escalation flag.
  8. Test in browser at /docs.

Why This Order

First prove the server is alive. Then prove JSON validation works. Then call the agent. This makes debugging simple because each layer has a separate proof.

Practice Check

Question: If /health works but /triage fails, what layer is probably broken?

Reveal answer

The server layer works. The issue is probably request parsing, agent invocation, output extraction, or credentials.

Question: If Uvicorn does not start, is your LangGraph agent definitely broken?

Reveal answer

No. The server/import/dependency layer may be broken before the agent even runs.
