Retrieval Choice Cheatsheet

Use this whenever you ask: should I use vector search, BM25/full-text search, or both?

Vector Search

Best when: the user asks by meaning, not exact wording.

Query: "How can work affect someone's mental wellbeing?"
Goal: retrieve chunks about mental health, work, stress, motivation.

BM25 / Full-Text Search

Best when: exact tokens matter.

Query: "schizo lunatic psycho terminology"
Goal: retrieve chunks containing those exact words.

Hybrid Retrieval

Best default for serious systems: run both, merge/rerank results, then send the best grounded chunks to the answer step.

vector_results = semantic_retriever(query)
bm25_results = lexical_retriever(query)
final_context = rerank_or_merge(vector_results, bm25_results)

Interview Rule

Say this plainly: "Vector search finds meaning. BM25 finds exact language. Hybrid retrieval protects you from both semantic misses and exact-match misses."
