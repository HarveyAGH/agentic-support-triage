FastAPI Agent Service Cheatsheet

FastAPI turns Python functions into URLs. Uvicorn keeps the app running and listening for HTTP requests.

Mental Model

without API:
terminal -> agent.py -> printed answer

with FastAPI:
external app -> HTTP request -> FastAPI endpoint -> agent.invoke() -> JSON response

Core Objects

app = FastAPI()

@app.post("/triage")
async def triage(request: TriageRequest):
    result = await agent.ainvoke(...)
    return TriageResponse(...)

What Each Piece Means

  • FastAPI app: the Python web application.
  • Uvicorn: the server process that runs the app.
  • Endpoint: a URL mapped to a Python function.
  • Request model: the input JSON shape.
  • Response model: the output JSON shape.
  • Swagger docs: automatic browser UI at /docs.

First Agent API Goal

POST /triage
input: customer message + thread id
output: final answer + routes called + escalation flag

Run Command

uv run uvicorn api.main:app --reload
