# Teaching Notes

- The learner prefers direct, practical explanations with concrete examples.
- Avoid slow one-by-one drip teaching when the learner asks for the full picture.
- The learner wants to understand concepts well enough to explain them in interviews, but also wants to use AI aggressively to move fast.
- The learner is sensitive to exaggerated resume claims. Keep wording honest and backed by working evidence.
- Best teaching pattern so far: explain the mental model, show the exact code location, run a small proof, then translate it into resume language.
- Current high-value next topics: MCP with FastMCP, FastAPI wrapper, async execution, Docker, hybrid retrieval.
